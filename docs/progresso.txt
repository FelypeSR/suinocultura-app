================================================================
  FIRESTORE — ESTRUTURA DE DADOS
================================================================

/animais/{animalId}
  - codigo:          string
  - sexo:            "macho" | "femea"
  - dataNascimento:  Timestamp
  - peso:            number (kg)
  - raca:            string
  - produtividade:   string (texto livre)
  - saude:           string (observações)
  - criadoEm:        Timestamp

/animais/{femea_id}/reproducoes/{reproducaoId}
  - machoUtilizadoId:     string (ref ao id do macho)
  - periodoCobertura:     Timestamp
  - gestacao:             number (dias, padrão ~114)
  - totalFilhotes:        number
  - mortalidadeFilhotes:  number
  - desmame:              Timestamp
  - criadoEm:             Timestamp

/usuarios/{userId}   ← já existia antes

  REGRAS DE NEGÓCIO IMPLEMENTADAS
